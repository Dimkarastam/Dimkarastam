## 🚀 About Me

I am a **Full-Stack Web Engineer and Founder** based in **Athens, Greece**. I build modern, resilient web applications and high-conversion digital platforms that combine speed, clean architecture, and practical AI automation.

- ⚡ **Core Philosophy:** Sub-second latency, accessible UI/UX (WCAG & European Accessibility Act compliant), strict type safety, and clean software architecture.
- 🌐 **Engineering Focus:** Edge-first computing (Cloudflare Workers/Pages, Hono), modern meta-frameworks (Astro, Next.js), and multi-tenant headless systems.
- 🤖 **Applied AI:** Production AI chat platforms with grounded knowledge retrieval, token cost controls, and Answer Engine Optimization (AEO/GEO).
- 💼 **Business Solutions:** Founder of **[Karastamatis Web Engineering](https://karastamatis.gr)** & **[DK Web Solutions](https://dkwebsolutions.gr)**, helping ambitious businesses turn technical performance into measurable growth.
